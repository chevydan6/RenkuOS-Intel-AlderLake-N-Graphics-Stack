## Unresolved issue

Production admission, retention, completion and cleanup calls are absent. Free and allocation-copyout rollback are unlocked and race admission; teardown needs the same explicit lock order without recursive acquisition. CLEANUP currently makes intel_free_memory return B_BUSY and has no production release-to-IDLE path. Completion must be a validated kernel observation matching owner and request generation. Timeout, owner close, stale/unconfirmed completion and failed cleanup must retain uncertain backing. These findings block a physical experiment with this implementation.
