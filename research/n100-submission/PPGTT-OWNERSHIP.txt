Lifecycle contract:
Build validates policy/window before retaining the backend context. Allocations
must fail without modifying output or acquiring hidden ownership. Successful
allocation must return one exclusively owned, pinned, writable4K page, stable
until token release; CPU and DMA mappings refer to that same backing. Allocator
must handle DMA translation/IOMMU as needed, not equate addresses by assumption.
A successful free relinquishes exactly its token; failed free leaves ownership
and safe retry intact. Backend release is infallible and occurs only when every
page is gone. Its code and context outlive every retained record.

Ready is offline readiness only. Release can reclaim Ready because this class
has no publication transition. Do not add GPU publication to this class without
changing lifetime/retirement semantics and independently reviewing all callers.
A module embedding a Retained or Ambiguous record must keep it resident until
cleanup succeeds or controlled reboot. Ambiguous has no in-place recovery.
Describe exposes diagnostic records, including zeroed released slots, and must
not be treated as ownership transfer. Root returns a modeled/allocated DMA root,
not authorization to program hardware. Raw-encoder PAT4..7 remain encodable but
constructor policy rejects them pending a supported hardware rationale.
