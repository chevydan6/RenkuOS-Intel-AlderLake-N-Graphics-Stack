# Public ACPI table admission

Objective 6c2292a98f534c696c60. Pinned source 4799bb5a188c4bb6bbef967287640cc21a061a0d plus patches through 0114.

BusManager.cpp public get_table and Module.cpp export retain their ABI and ready lookup success/failure semantics. A private interrupt-safe spinlock serializes starting, ready publication, table admission and irreversible retained closure. The lock is released before ACPICA and producer closure calls. No in-flight counter is needed: retained module image/dependency custody supports preclosure operations and escaped references. Call completion never releases a table reference. Closure does not wait or terminate ACPICA, put tables, release dependencies or delete resources.

Caller audit: public users are bcm2711_emmc2, ECAMPCIControllerACPI, radeon_hd, brcmfmac vc_mailbox, hpet and x86 ioapic. They obtain the ACPI module before lookup. ioapic_init obtains it before MADT access. ACPI bus initialization calls arch_init_interrupt_controller and embedded_controller_probe_ecdt before readiness; the latter legitimately reads ECDT using direct AcpiGetTable, which remains unchanged. No public wrapper startup dependency was found. Module.cpp binds get_table as the final ACPI module operation. ACPICA internal calls remain unchanged.

Host tests compose production patches, extract actual get_table, lifecycle state/lock and retained closure, and exercise unused/starting rejection, ready success/failure, close-before-entry, repeated closure and paused success/failure overlapping closure. Ready publication is source-checked, not a full acpi_std_ops runtime test. TERRA must independently verify initialization ordering and publication, including closure during initialization preventing reopening. Callback/DPC and interrupt regressions remain required. ASan/UBSan use detect_leaks=0 for the known traced LeakSanitizer restriction. No native kernel or GPU execution, byte immutability, trusted DMAR snapshot, callback cessation or cleanup proof is claimed.
