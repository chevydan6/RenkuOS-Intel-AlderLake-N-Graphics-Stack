# Research and experimental evidence index

- `n100-submission/`: design proposals, memory ownership, DMA, power, context and completion research.
- `terra-n100/`: independent research, source snapshots, checks and provenance.
- `local-model-evaluation/`: agent/model evaluation evidence; **not GPU driver validation**.

Research conclusions must be linked to implementation commits and hardware/VM evidence before being promoted to verified status. See [current status](../docs/CURRENT_STATUS.md).
